# 随页汇率

随页汇率是一款 Chrome 扩展，会识别网页文字中的金额，并在原价旁显示目标货币的参考金额。例如，目标货币设为人民币、假设 1 美元兑换 7 元人民币时，商品价格 `US$20.00` 旁会出现 `≈ CNY 140.00`。

## 安装

1. 下载 [随页汇率.zip](releases/随页汇率.zip) 并解压。如果已经克隆了本仓库，可直接使用 [source](source/) 目录，无需构建。
2. 在 Chrome 地址栏打开 `chrome://extensions/`，开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。从仓库安装时请选择 `source/`。
4. 刷新已打开的购物或旅行网页。首次使用需要联网获取汇率。

## 使用

点击 Chrome 工具栏中的「随页汇率」，在「换算为」下拉框中选择目标货币。默认目标为人民币（CNY）。切换后，已打开页面上的换算标签会随之更新。关闭面板右上角的开关即可暂停换算并移除标签。

| 网页上的写法 | 识别方式 |
| --- | --- |
| `US$19.99`、`HK$128`、`NT$500` | 根据符号前缀区分美元、港元和新台币 |
| `1.299,50 €`、`EUR 1,299.50` | 两种写法均识别为 1,299.50 欧元 |
| `250 美元`、`800 日元` | 根据中文币种名称识别 |
| `$50`、`¥500` | 默认分别按美元和人民币识别，可在「通用符号的来源币种」中修改 |

来源币种设置对所有网页生效。例如，在日本网站浏览仅标为 `¥` 的价格时，可将 `¥ / ￥` 的来源设为日元（JPY），目标仍选人民币。原价与目标币种相同时，扩展会跳过该金额。

扩展会跟随动态加载的商品和价格变化更新标签。识别范围为 HTTP 和 HTTPS 网页中的文本，包括部分将币种符号与数字拆开排版的价格。图片中的价格、输入框和代码块不参与换算。

## 汇率与隐私

汇率来自 ExchangeRate-API 的开放接口，每日更新，无需 API 密钥。将鼠标悬停在换算标签上即可查看汇率日期。缓存到期后，扩展会在下次需要数据时请求更新；若请求失败且已有缓存，则继续使用上次的汇率，面板底部会显示缓存日期。[汇率服务说明](https://www.exchangerate-api.com/docs/free)

金额识别和换算都在浏览器内完成。扩展的后台仅向 `open.er-api.com` 请求以美元为基准的汇率表，请求中不包含网页地址、正文或识别到的金额。`storage` 权限用于在本机保存目标货币、符号设置、开关状态和汇率缓存。

## 本地开发

扩展使用 Manifest V3 和原生 JavaScript。金额识别规则位于 [money.js](source/money.js)，网页扫描与标签渲染位于 [content.js](source/content.js)，汇率获取与缓存位于 [background.js](source/background.js)。修改源码后，在 `chrome://extensions/` 中点击扩展的重新加载按钮，再刷新测试网页。
